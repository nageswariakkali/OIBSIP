# Basic Weather App

A Python command-line tool that fetches real-time weather data 
for any city using the OpenWeatherMap API.

## How to run
python weather_app.py

## Features
- Takes city name as input
- Fetches live weather data (temperature, humidity, wind speed, condition)
- Displays temperature in both Celsius and Fahrenheit
- Handles errors: empty input, city not found, network issues
